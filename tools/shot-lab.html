Shot Lab

Test bench for the sniper's sounds. In the game plays the recordings the game uses, with the game's processing, so the sliders show what a change would sound like in game. Synth keeps the best of the sounds generated from scratch while the shot was being tuned (Lab 1's #10 and variations on it).

Keys: G game shot + bolt, B bolt only, 1–9, 0 synth versions, Space repeats. Letting go of a slider fires the sound. Uses the same volume and room reverb as the game. Back to the game
